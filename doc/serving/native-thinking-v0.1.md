## Initial reasoning prefix

The supervisor suppresses generated text through the first complete `</think>` delimiter.
The template already supplies the opening tag in the prompt.
Retain only a possible closing-delimiter suffix between text deltas.
Count discarded bytes without retaining the full reasoning prefix.
The first complete closing delimiter permanently opens this prefix filter.
Pass remaining text and all subsequent deltas unchanged to the existing stop matcher.
Pass stop-selected text to the existing MiniCPM tool parser.

The prefix filter never interprets a later `<think>` tag.
This rule preserves literal delimiters inside tool parameters and CDATA.
The existing parser still suppresses later think blocks in its text state.
The existing stop matcher still sees those later blocks before the parser.
Stops inside later blocks retain their previous behavior.
This profile does not provide a general reasoning channel.

## Completion and settlement

A completed length result before the first close returns empty content and full usage.
It retains the existing length or max-tokens public stop reason.
Discard an incomplete closing-delimiter suffix for that result.
A completed EOS result without the first close returns `internal_error` for incomplete model output.
After the filter opens, retain existing parser completion rules.
Worker failure, cancellation, and expiry retain their existing public outcomes.
A partial reasoning prefix must not replace those outcomes with a parser error.
Capacity remains held until resource release or worker recovery.
